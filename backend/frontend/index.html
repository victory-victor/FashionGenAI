How a request becomes images

The same pipeline you use on the Generator page, step by step.

1. Understand

An LLM (Gemini) turns text into JSON. A rule-based parser takes over if no API key is set.

2. Validate

Pydantic checks the category, class ID (0–9) and image count before anything is generated.

3. Generate

The Conditional GAN receives noise plus the class ID and outputs 28×28 images.

4. Evaluate

CLIP scores each image against the text description, and the gallery shows the scores.

What is inside

Conditional GAN

Generator and discriminator both receive the class label, so you can ask for a specific item.

Variational Autoencoder

A conditional VAE trained on the same data, for a side-by-side comparison with the GAN.

BERT + CLIP

DistilBERT cross-checks the category; CLIP measures image–text similarity.

Real training data

Loss curves and sample grids come from the saved training run, never typed in by hand.

Measured evaluation

Ten test prompts and class-wise CLIP scores computed by running the models.

Responsible AI

Dataset licence, limits of CLIP, failure cases and bias notes are documented in the app.

Project information

P14 – Text-to-Conditional-GAN Bridge. A college Generative AI mini-project covering foundations of generative AI, GANs and LLMs, GPT/BERT/multimodal models, generative AI tooling and responsible AI. Source code and documentation are in the project repository. Fashion-MNIST images are 28×28 and grayscale, so results are research samples rather than realistic product photos.

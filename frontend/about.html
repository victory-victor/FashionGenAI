About & Responsible AI

What the project does, how each model works, and where it falls short.

Project objectives

  • Bridge natural language and a class-conditional image generator.
  • Compare a GAN and a VAE trained on the same data.
  • Evaluate outputs with real, reproducible measurements.

Generative AI basics

Discriminative models learn p(y|x), the label given an image. Generative models learn the data distribution p(x), or p(x|y) when conditioned on a label, so they can sample new images. Lifecycle: define the problem, prepare data, choose and train a model, evaluate, deploy, monitor.

GAN, generator and discriminator

The generator maps random noise plus a class label to an image. The discriminator sees an image plus a label and predicts real or fake. They train against each other until generated images look real. Conditioning means both networks receive the label, so “ankle boot” really asks for an ankle boot.

Variational Autoencoder

An encoder maps an image to a Gaussian in latent space; a decoder rebuilds the image from a sample. The loss is reconstruction error plus a KL term that keeps the latent space smooth. Sampling the latent space produces new images, usually blurrier than a GAN’s.

LLM integration

A prompt asks Gemini to return JSON (category, class_id, count). We compare zero-shot (instructions only) and few-shot (instructions plus examples) prompting via /api/parse-prompt. The JSON is validated with Pydantic before use. Without an API key a rule-based parser is used and the response says so.

BERT and CLIP

DistilBERT (a BERT-family encoder) embeds the request and class descriptions; cosine similarity gives an independent cross-check of the category, without fine-tuning. CLIP embeds images and text in one space; we report image–text cosine similarity and CLIP’s top-1 label.

Fashion-MNIST

70,000 grayscale 28×28 images (60,000 train, 10,000 test) in 10 classes, by Zalando Research. Class IDs: 0 T-shirt/top, 1 Trouser, 2 Pullover, 3 Dress, 4 Coat, 5 Sandal, 6 Shirt, 7 Sneaker, 8 Bag, 9 Ankle boot.

Limitations and responsible use

Dataset limitations

  • Tiny 28×28 grayscale images; no colour, texture or fine detail.
  • Only 10 coarse classes, centred product shots from one retailer: limited style and cultural diversity.
  • “Bag”, “Shirt”, “Pullover” and “Coat” overlap visually, which makes them harder classes.

Model limitations

  • The GAN can show mode collapse or artefacts; the VAE is blurry.
  • Models only know the 10 classes: unknown items are rejected by the parser, not generated.
  • Small training budget (see the Training page for the real epoch count).

Limits of CLIP evaluation

  • CLIP was not trained for low-resolution grayscale images, so scores are low and noisy.
  • Similarity is not accuracy. A high score does not prove the image is a correct item.
  • Prompt wording (“a photo of a handbag”) changes the score.

Ethical considerations

  • Generated images are synthetic and must not be presented as real product photos.
  • Bias analysis is limited to class-wise performance; the dataset has no people, but it reflects one retailer’s catalogue.
  • The LLM only receives the user’s request text. API keys stay on the server and are never sent to the browser.

Responsible AI disclaimer: this is an educational prototype. Outputs are experimental, scores are indicative only, and the system should not be used for commercial decisions without further validation.
